# Hotel Boutique — Proyecto completo

## Estructura
- `index.html` — página principal del proyecto.
- `style.css` — estilos de la página principal.
- `script.js` — comportamiento de la página principal.
- `game/index.html` — juego Trivia.
- `game/style.css` — estilos del juego.
- `game/script.js` — lógica del juego.

## Cómo subirlo a GitHub
1. Descarga este proyecto y descomprime el ZIP.
2. Abre tu repositorio de GitHub.
3. Sube `index.html`, `style.css`, `script.js` y la carpeta `game`.
4. Reemplaza los archivos anteriores cuando GitHub lo solicite.
5. En GitHub Pages, usa la rama principal (`main`) y la carpeta raíz (`/root`) como fuente.
6. Abre el enlace de tu GitHub Pages.

El botón “Abrir juego” lleva directamente a la sección de la trivia y el juego está dentro de la misma página mediante `game/index.html`.
