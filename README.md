# Página web integrada — Hotel Boutique

Página completa del proyecto con la mecánica #2: Preguntas y Respuestas (Trivia).

Incluye:
- Inicio del proyecto.
- Problema.
- Solución.
- Propuesta de valor.
- Trivia integrada dentro de la misma página.
- Publicidad/promoción de 5 segundos entre rondas.
- Resultado con puntuación, rating simulado y diagnóstico.

## GitHub Pages
Sube los cuatro archivos al repositorio y usa:
Settings → Pages → Deploy from a branch → main → / (root).
